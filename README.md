# Indian Agricultural Crop Production Analysis

## Project Overview
This project focuses on analysing Indian agricultural crop production data using data analytics and visualization techniques.

## Objectives
- Analyse crop production across different Indian states.
- Identify top-producing crops and states.
- Study yearly and seasonal production trends.
- Explore the relationship between cultivated area and production.
- Design an interactive agribusiness dashboard.

## Tools and Technologies
- Python
- Pandas
- Matplotlib
- Seaborn
- Tableau
- Figma
- GitHub

## Dataset
The dataset contains information about states, districts, crop years, seasons, crops, cultivated area, and production.

## Project Work
1. Data collection
2. Data cleaning
3. Descriptive analytics
4. Data visualization
5. Dashboard design
